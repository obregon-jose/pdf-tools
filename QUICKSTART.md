# 🚀 RADICOR - Inicio Rápido

## Instalar y Ejecutar

```bash
# Instalar
pip install -r requirements.txt

# Ejecutar
python main.py
```

## Herramientas

**PDF**: Unir, Dividir, Eliminar páginas, Multiplicar  
**RADICACIÓN**: Agrupar, Separar órdenes, Verificar  
**DATOS**: Validar emails, Carnets, Vacunas, Horus, Web PAI

## Ejemplo: Unir PDFs

1. Abre RADICOR
2. Selecciona "Unir PDFs"
3. Elige archivos
4. Define salida
5. Ejecuta

## Configuración

`data/config.json`:
```json
{
    "theme": "light",
    "color_theme": "blue"
}
```

## Problemas

**No inicia**: `pip install -r requirements.txt --force-reinstall`  
**Lento**: Usa PDFs más pequeños  
**No guarda**: Verifica permisos en `data/`
